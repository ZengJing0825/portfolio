## 用 AI 做金融产品增长

八年用户增长，四年 crypto，近三年自己动手做 AI agent 产品。
下面是一条完整闭环的六步，每一步都有代码或规则可查。

**1. 定义输出：agent 该说什么、不说什么**
五套输出模板，三条硬规则（首屏只放结论、一页只回答一个问题、digest 是推送不是看板），
三道 grounding 闸门写进模板，规则可机械检查。

**2. 做成 agent：让规则每天自动跑**
按事件排序而不按标的；标的异动却没有自身新闻时，反向查同行和板块；
每条带「意味着什么、盯什么」的决策透镜；持仓支持手填、截图、券商直连三种接入。

**3. 评好坏：发版前知道是好是坏** → [agent-eval-harness](https://github.com/ZengJing0825/agent-eval-harness)
先把题和答案做对再评 agent：一人出题一人复核；四层题集各设目标；
裁判带版本号并做人工抽检校准；坏例先归因再回流题集。

**4. 推给用户：没事闭嘴，有事说人话** → [ticker-digest](https://github.com/ZengJing0825/ticker-digest)
无事不推；同一件事只在恶化时重推；一套信号按标的、按人、按持仓三种切片；
有仓位时按权重乘波动排序；每次运行留审计记录，没推也写清为什么。

**5. 守住质量：坏内容和坏数据别上首页**
评分规则门槛先行，通用维度加技能维度，一个缺陷只在一个维度扣分，最后分档；
每小时巡检首页内容，十层检测区分「空」和「坏」。

**6. 拉来用户并归因：每一块投放钱追到动作** → [ga4-ads-dashboard](https://github.com/ZengJing0825/ga4-ads-dashboard)
先埋点再投放；GA4 与自有数据库逐日对账；按承接页类型拆看而不是只看总数；
每个改动走诊断、假设、小预算、对照、关停或加量。

第 6 步的数据回到第 1 步，继续改输出。
